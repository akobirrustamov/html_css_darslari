## 🚀 Qanday foydalanish kerak

1. Repozitoriyani yuklab oling:
   ```bash
   git clone https://github.com/akobirrustamov/html_css_darslari.git
   ```
2. `index.html` faylini brauzerda oching. U yerda barcha modullar ro'yxati bor.
3. Har bir modul papkasidagi `index.html` shu darsning slaydlari va misollarini ochadi.

Hech narsa o'rnatish shart emas: faqat brauzer va kod muharriri (masalan, [VS Code](https://code.visualstudio.com/)) yetarli.
