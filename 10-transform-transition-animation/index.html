CSS Transform, Transition va Animatsiyalar:
saytga «jonlilik» qo'shish

Sichqoncha tugma ustiga kelganda u sekin-asta kattalashadi, sahifa yuklanayotganda aylanuvchi doiracha (loading spinner) paydo bo'ladi — bularning hech biri "sehr" emas. Bugun buni tashkil etuvchi uchta narsani o'rganamiz: elementni harakatlantirish (transform), buni silliq qilish (transition) va uni o'zi-o'zidan takrorlanadigan animatsiyaga aylantirish (@keyframes).

15 daqiqadan keyin

Reja 1 · Nazariya

transform: ko'rinishni o'zgartirish, layoutni buzmasdan

transform xossasi elementning ko'rinishini o'zgartiradi, lekin muhimi — sahifadagi boshqa elementlarning joylashuvini "buzmaydi". Agar margin orqali joy o'zgartirsangiz, atrofdagi elementlar ham suriladi; transform esa faqat vizual — xuddi elementning "soyasi"dek harakat qiladi.

🔍

scale()

scale(1.2) — elementni 1.2 barobar kattalashtiradi. 1dan kichik son bo'lsa — kichraytiradi.

🔄

rotate()

rotate(45deg) — elementni gradusga (deg) burib yuboradi.

↔️

translate()

translate(20px, 10px) — elementni X (o'ng-chap) va Y (yuqori-past) bo'yicha suradi.

Bir nechta transformatsiyani birlashtirish

Bitta elementga bir nechta transformatsiyani bir vaqtda, bo'sh joy bilan ajratib, bitta transform ichida yozish mumkin: transform: scale(1.1) rotate(5deg);

Reja 1 · Muhim farq

translate() joy egallamaydi

translate ichidagi qiymatlar margin yoki position kabi joyni "haqiqatan" o'zgartirmaydi — element hujjat oqimida (document flow) o'z eski joyini "band qilib" turadi, atrofidagilar surilmaydi, faqat elementning o'zi ko'rinishda ko'chadi.

✓ transform: translate()
.karta:hover {
  transform: translateY(-10px);
}
/* atrofdagi kartochkalar joyidan
   qo'zg'almaydi — faqat vizual siljish */

Element ko'zga "ko'chgandek" ko'rinadi, lekin uning asl o'rni layoutda hali ham band — qo'shni elementlar buni sezmaydi.

✗ margin / position
.karta:hover {
  margin-top: -10px;
}
/* pastdagi barcha elementlar ham
   yuqoriga suriladi — layout "sakraydi" */

Bu holatda joy haqiqatan bo'shaydi — atrofdagi barcha elementlar qayta joylashadi, sahifa "titraydi".

Xulosa

Kartochkani hover'da "ko'tarish" effekti uchun margin emas, aynan transform: translateY() ishlatiladi — chunki u atrofdagi elementlarga hech qanday ta'sir qilmaydi.

Reja 2 · Nazariya

transition: holatlar orasida silliq o'tish

Avvalgi modullarda :hover bilan rang yoki o'lcham o'zgarishini ko'rgan edik, lekin u "sirpanib" emas, sakrab o'zgargandi. transition aynan shu sakrashni yo'qotib, ikki holat orasini silliq qiladi.

.box {
  width: 120px;
  height: 120px;
  background: #4a6cf7;
  transition: transform 0.3s ease-in-out, background 0.3s ease;
}

.box:hover {
  transform: scale(1.15);
  background: #2f46b0;
}
QismVazifasi
Xossa (property)Qaysi CSS xossasi kuzatilsin — transform, background, yoki barchasi uchun all
Davomiylik (duration)Necha soniyada tugasin — 0.3s, 300ms
easeSekin boshlanib, tezlashib, sekin tugaydi (tabiiy his, standart qiymat)
linearBoshidan oxirigacha bir xil tezlik — mexanik his beradi
ease-in-outIkkala uchida ham sekinlashadi
Muhim: transition qayerga yoziladi?

transition odatda elementning asosiy (bazaviy) holatiga yoziladi, :hoverga emas — shunda u faqat kirishda emas, chiqishda (sichqoncha olib qochilganda) ham silliq qaytadi. Aks holda sichqoncha chiqib ketganda element darhol, sakrab eski holatiga qaytadi.

transition qatoridagi davomiylik va easing (timing-function) qiymatlarini o'zgartiring. Keyin uni butunlay o'chirib, farqni his qiling — o'tish yana qo'pol, sakrab bo'lib qoladi.

Sinab ko'ring

Reja 3 · Nazariya

@keyframes va animation: o'zi-o'zidan ishlaydigan harakat

transition faqat ikkita holat (boshlanish va tugash) orasida ishlaydi va odatda foydalanuvchi harakatiga (:hover kabi) bog'liq. Lekin agar biror narsa sahifa ochilishi bilan o'zi-o'zidan, uzluksiz harakatlanishi kerak bo'lsa (masalan spinner doim aylanib tursin) — bunga @keyframes kerak.

@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

.spinner {
  animation: spin 1s linear infinite;
}

@keyframes animatsiyaning "nomini" (bu misolda spin) va yo'lda qanday bosqichlardan o'tishini belgilaydi — foizlarda (0%, 50%, 100%) yoki shunchaki from/to bilan. So'ng shu nomni elementga bog'lash uchun kamida to'rtta xossa kerak bo'ladi:

XossaVazifasi
animation-nameQaysi @keyframesga bog'lansin
animation-durationBir marta aylanish qancha davom etadi
animation-timing-functionTezlik egri chizig'i — linear, ease
animation-iteration-countNecha marta takrorlanadi — raqam yoki cheksiz uchun infinite
animationBarchasi uchun qisqartma (shorthand): spin 1s linear infinite
Reja 3 · Jonli mashq

Bosqichli animatsiya: 0%, 50%, 100%

from/to — bu shunchaki 0%/100%ning qisqa yozilishi. Agar oraliqda qo'shimcha bosqich kerak bo'lsa (masalan yarim yo'lda rang ham o'zgarsin), foiz qiymatlardan foydalaniladi. Nomlarni tekshiring: @keyframes nomi va animation-name bir xil yozilganiga ishonch hosil qiling.

Amaliy misol 2

Eng muhim maslahat

Animatsiya "umuman ishlamayapti" desangiz — birinchi tekshiring: @keyframes nomi va animation-name bir xilmi. Bu xatolik konsolda hech qanday xato chiqarmaydi.

Best practice

Yaxshi amaliyot — qisqacha

  • transitionni har doim asosiy (bazaviy) holatga yozing, :hoverga emas.
  • transformni faqat vizual effekt uchun ishlating — u atrofdagi elementlarni surmaydi.
  • Cheksiz aylanuvchi elementlar (spinner) uchungina animation-iteration-count: infinite ishlating.
  • @keyframes nomini va animation-nameni aynan bir xil yozing — imloni ikki marta tekshiring.
  • Iloji bo'lsa animation qisqartmasidan (shorthand) foydalaning — kod qisqa va o'qish oson bo'ladi.

Savol-javob

1. transform: translate(50px, 0) berilgan element atrofidagi boshqa elementlarni suradimi?

Yo'q. transform faqat vizual o'zgarish — element hujjat oqimida (document flow) o'z eski joyini "band qilib" turadi, atrofdagilar surilmaydi.

2. transition qaysi holatga — asosiy selektorgami yoki :hovergami — yozilishi kerak?

Asosiy (bazaviy) selektorga. Faqat shunda o'zgarish ham holatga kirishda, ham undan chiqishda silliq bo'ladi. Agar transition faqat :hover ichida yozilsa, sichqoncha olib qochilganda holat bir zumda, qo'pol qaytadi.

3. @keyframes spin deb yozib, animation: spinn 1s linear infinite; deb xato yozilsa nima bo'ladi?

Hech qanday xatolik konsolda chiqmaydi, lekin animatsiya umuman ishlamaydi — chunki brauzer spinn nomli @keyframesni topa olmaydi. Ikkala joydagi nom aynan bir xil bo'lishi shart.

4. animation-iteration-count: infinite nimani anglatadi?

Animatsiya to'xtovsiz, cheksiz takrorlanaveradi — masalan loading spinner uchun mos. Agar bu qiymat tasodifan qoldirilib ketsa, bir marta ishlashi kerak bo'lgan animatsiya ham to'xtamay davom etadi.

5. Modal oynani ochish/yopishda nega transition ishlatiladi, @keyframes emas?

Chunki modalda faqat ikkita holat bor — yopiq va ochiq — va o'tish foydalanuvchi harakatiga (tugma bosish) bog'liq. @keyframes esa foydalanuvchi harakatidan mustaqil, o'zi-o'zidan takrorlanadigan animatsiyalar (masalan spinner) uchun mo'ljallangan.
