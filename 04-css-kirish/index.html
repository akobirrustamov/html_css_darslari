CSS ga kirish:
sahifangizga birinchi rangni bering

Birinchi uchta darsda faqat HTML bilan ishladik — sarlavhalar, jadvallar, havolalar. Hammasi funksional ishladi, lekin oq fon va qora matndan nariga o'tmadi. Bugundan boshlab CSS (Cascading Style Sheets) bilan tanishasiz — bu kursning eng katta burilish nuqtasi.

Maqsad

Dars oxirida siz nima qila olasiz

Bu darsdan keyin siz istalgan HTML sahifani uchta usulning biri bilan CSS'ga ulay olasiz, har bir CSS qoidasini selector-property-value sifatida o'qiy olasiz va class, id, tag hamda universal selektorlar orqali aynan kerakli elementga uslub bera olasiz.

🔌

Ulaysiz

Inline, internal va external — CSS'ni sahifaga ulashning uchala usulini va qachon qaysi birini ishlatishni.

✍️

O'qiysiz

Muhim eslatma

Ranglarni yozish usullari (HEX, RGB) — 05-modulda, inheritance (merosxo'rlik) esa 06-modulda. Bugun faqat CSS'ning fundamentiga — ulash usullari va selektorlarga — e'tibor qaratamiz.

Reja 1 · Nazariya

CSS nima — "Cascading Style Sheets"

01-modulda uchta qatlamni eslang: HTML — skelet (ma'no), CSS — ko'rinish, JavaScript — xatti-harakat. Bugun o'sha ikkinchi qatlamga birinchi marta kirib boramiz.

HTML ma'no beradi, CSS ko'rinish beradi

Bir xil HTML elementi — masalan <h1> — har doim "bu sahifaning bosh sarlavhasi" degan ma'noni bildiradi. Lekin u qanday ko'rinishda chiqishi — qora rangdami, katta shriftdami, markazlashganmi — buni CSS hal qiladi.

Analogiya

HTML — uyning g'ishtlari va devorlari: qayerda xona, qayerda eshik. CSS — uyning dizayni, ranglari va bezaklari: devorlarni buzmasdan, uyni butunlay boshqacha ko'rinishga keltirish mumkin.

Bugungacha nima ko'rgan edik

Agar hozir 3-darsdagi jadvalingizni ochib ko'rsangiz — u funksional ishlaydi, lekin chiroyli emas, hatto biroz zerikarli ko'rinadi. Sababi oddiy: unga hali CSS berilmagan.

Bugundan boshlab sahifalarimiz rangga, shriftga va joylashuvga ega bo'lib, haqiqiy zamonaviy saytlarga o'xshab qoladi.

Reja 1 · Asosiy

CSS'ni sahifaga ulashning 3 usuli

CSS qoidalarini yozish uchun uchta joy bor. Ulardan faqat bittasi haqiqiy loyihalarda ishlatiladi — lekin qolgan ikkitasini ham tanib olishingiz kerak.

UsulQayerda yoziladiQachon ishlatiladi
InlineElementning o'zida, style="" atributidaFaqat bitta elementga. 10 ta elementga bir xil uslub kerak bo'lsa, har biriga alohida yozish kerak — shuning uchun katta loyihalarda deyarli ishlatilmaydi.
Internal<head> ichidagi <style> blokidaButun sahifaga ta'sir qiladi, lekin faqat o'sha bitta HTML faylga tegishli. 10 ta sahifa bo'lsa, uslubni har biriga alohida nusxalash kerak bo'ladi.
ExternalAlohida .css faylda, <link> orqali ulanadiStandart va tavsiya etiladigan usul. Bitta fayl bir nechta sahifaga ulanadi — dizaynni bir joyda o'zgartirsangiz, hammasida o'zgaradi. Butun kurs davomida shundan foydalanamiz.

1. Inline

<h1 style="color: red;">Salom</h1>

2. Internal

<head>
  <style>
    h1 {
      color: red;
    }
  </style>
</head>

3. External

<head>
  <link rel="stylesheet" href="style.css">
</head>
h1 {
  color: red;
}
Talabalar ko'p adashadigan joy

<link> tagida href yo'lini noto'g'ri yozish eng ko'p uchraydigan xato — masalan CSS fayl boshqa papkada bo'lsa-yu, to'g'ridan-to'g'ri nom yozilsa, uslub umuman ishlamaydi va sahifa hech qanday xatosiz, "jim" qolib ketadi. Har doim CSS fayl va HTML fayl qayerda joylashganini tekshiring.

Reja 2 · Nazariya

Asosiy tushunchalar: Selector, Property, Value

Har bir CSS qoidasi uchtadan qismdan iborat — buni gap tuzilishiga o'xshatib eslab qoling: KIM — NIMASINI — QANDAY qiladi.

h1     {  color:      blue;  }
 │            │           │
 │            │        VALUE — qanday qiymat beriladi
 │        PROPERTY — qaysi xususiyat o'zgaradi
SELECTOR — qaysi elementga

Selector (selektor) — "KIM"

Qaysi HTML elementga uslub berilayotganini ko'rsatadi (masalan h1).

Property (xususiyat) — "NIMASINI"

O'sha elementning qaysi xususiyati o'zgartirilayotganini bildiradi (masalan color — rang, font-size — shrift o'lchami).

Value (qiymat) — "QANDAY"

O'sha xususiyatga qanday qiymat berilayotganini bildiradi (masalan blue, 32px).

h1 {
  color: blue;
  font-size: 32px;
}
Talabalar ko'p adashadigan joy

Property va value orasida ikki nuqta (:) o'rniga teng belgisi (=) yozish, yoki qator oxirida nuqta-vergul (;) qo'yishni unutish — bu ikkalasi ham CSS'ni "sindiradi" va uslub ishlamay qoladi.

Reja 3 · Asosiy

Selektor turlari: Tag, Class, ID, Universal

Selektor — "qaysi elementga" degan savolga javob. To'rtta asosiy turini bilib oling.

SelektorYozilishiNimani tanlaydi
Tagp { }Sahifadagi shu turdagi barcha elementlarni. Umumiy, global uslublar uchun qulay.
Class.karta { }Nuqta (.) bilan boshlanadi. class="karta" bo'lgan barcha elementlarga ta'sir qiladi — bir nechta elementga bir xil class berish mumkin.
Id#header { }Pag'ona (#) bilan boshlanadi. id="header" bo'lgan bitta, noyob elementga ta'sir qiladi — bir sahifada bir marta ishlatiladi.
Universal* { }Yulduzcha (*). Sahifadagi absolyut barcha elementga ta'sir qiladi — ko'pincha standart bo'shliqlarni (margin, padding) nolga tushirish uchun ("reset") ishlatiladi.
Class nomlash qoidalari

Class nomi kichik harflar bilan yoziladi; agar bir necha so'zdan iborat bo'lsa tire (-) orqali qo'shiladi (masalan baholar-jadvali, probel yoki katta harf ishlatilmaydi) va raqamdan boshlanmasligi kerak.

<table class="baholar-jadvali">
  <tr>
    <th>Ism</th>
    <th class="baho-ustuni">Baho</th>
  </tr>
  <tr>
    <td>Aziz Karimov</td>
    <td class="baho-ustuni">92</td>
  </tr>
</table>
/* Universal selektor - hamma narsani nollashtirish */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* Tag selektor - barcha jadvallarga */
table {
  border-collapse: collapse;
  width: 100%;
}

/* Class selektor - faqat shu klassdagi elementlarga */
.baholar-jadvali {
  border: 2px solid #333;
}

.baho-ustuni {
  color: green;
  font-weight: bold;
  text-align: center;
}

/* ID selektor - faqat bitta, noyob elementga */
#asosiy-sarlavha {
  color: darkblue;
}
Talabalar ko'p adashadigan joy

Class va ID belgilarini chalkashtirish eng keng tarqalgan xato — nuqta (.) class uchun, pag'ona (#) ID uchun. Yana bir xato — ID'ni bir sahifada bir necha marta ishlatish: texnik jihatdan brauzer buni "yutib yuboradi", lekin bu noto'g'ri amaliyot va katta loyihalarda muammolarga olib keladi.

Nega aynan shunday

Id juda kuchli va noyob bo'lgani uchun, uni ko'p ishlatish loyiha kattalashganda CSS'ni tartibga solishni qiyinlashtiradi. Class esa qayta-qayta ishlatilishi mumkinligi bilan moslashuvchan qoladi — shuning uchun stillash uchun asosan classdan foydalaning.

Amaliy vazifa

Uyga vazifa — 3-dars jadvalini bezang

1 3-darsdagi jadval sahifangizni CSS bilan jonlantiring

  1. 3-darsda yaratgan jadval sahifangizni qaytadan oching.
  2. Alohida style.css fayl yarating va uni <link rel="stylesheet" href="style.css"> orqali <head>ga ulang (External usul).
  3. Tag selektor orqali jadvalga umumiy chegara (border) bering — masalan table { border-collapse: collapse; }.
  4. Kamida bitta class selektor yarating (masalan sarlavha qatoriga yoki maxsus ustunga) va unga rang yoki shrift qalinligi bering.
  5. Kamida bitta id selektor orqali jadvalning umumiy konteyneriga yoki sarlavhasiga noyob uslub qo'llang.

Namuna sifatida ushbu darsda ko'rgan baholar-jadvali misolini asos qilib olishingiz mumkin, lekin o'z ranglaringiz va uslubingiz bilan ijodiy yondashing.

Baholash mezoni: CSS alohida .css faylda yozilgan va <link> orqali to'g'ri ulangan (External usul) · kamida bitta tag, bitta class va bitta id selektor ishlatilgan · class nomlari to'g'ri qoidada (kichik harf, tire bilan, probelsiz) · sahifa Live Server orqali ochilganda uslublar haqiqatan ko'rinadi.

Savol-javob

1. Inline, internal va external CSS o'rtasidagi asosiy farq nima va qaysi biri tavsiya etiladi?

Inline — elementning style="" atributida, internal — <head>dagi <style> blokida, external — alohida .css faylda va <link> orqali ulanadi. External tavsiya etiladi, chunki bitta fayl bir nechta sahifaga ulanadi va dizaynni bir joyda o'zgartirish mumkin.

2. h1 { color: blue; font-size: 32px; } qoidasida qaysi qism selector, qaysisi property va qaysisi value?

h1 — selector (qaysi elementga), color va font-size — property (qaysi xususiyat), blue va 32px — value (qanday qiymat).

3. Class va id selektorlari qanday belgi bilan yoziladi va ular orasidagi asosiy farq nima?

Class — nuqta (.) bilan, bir nechta elementga takror ishlatilishi mumkin. Id — pag'ona (#) bilan, bitta sahifada faqat bitta, noyob elementga ishlatilishi kerak.

4. Universal selektor (*) nimaga ta'sir qiladi va odatda nima uchun ishlatiladi?

Sahifadagi absolyut barcha elementga ta'sir qiladi. Odatda barcha elementlarning standart bo'shliqlarini (margin, padding) nolga tushirish uchun — buni "reset" deb atashadi.

5. Bu CSS kodida nechta sintaksis xatosi bor? .karta { color: red font-size: 16px }

Bitta xato: color: red dan keyin nuqtali vergul (;) yo'q — shuning uchun brauzer red font-size: 16px ni bitta noto'g'ri qiymat deb o'qiy boshlaydi va ikkala deklaratsiya ham ishlamay qolishi mumkin. To'g'risi: .karta { color: red; font-size: 16px; }
