Reja 1 · Nazariya

Brauzer va server — mijoz-oshxona metaforasi

Brauzer (browser) — Chrome, Safari, Edge kabi dasturlar bo'lib, ular internetdagi sahifalarni o'qib, ekranda chiroyli ko'rinishda ko'rsatib beradi. Internet esa katta restoran kabi ishlaydi.

Restoran metaforasi

  • Siz — mijoz (Client), ya'ni brauzeringiz.
  • Ofitsiant — sizning so'rovingizni oshxonaga yetkazadi.
  • Oshxona — server (Server), taomni (sahifani) tayyorlaydi.
  • Taom orqaga qaytadi — bu javob (response).

Xuddi shunday: brauzer serverga «menga shu sahifani ber» deb so'rov (request) yuboradi, server esa HTML faylni qaytaradi. Bu — Client-Server modeli.

Nima uchun bu muhim?

Frontend dasturchi bo'lish uchun aynan shu jarayonni — brauzeringiz bilan uzoqdagi server o'rtasidagi «muloqotni» — tushunish kerak. Bugundan boshlab siz yozadigan har bir HTML sahifa aynan shu yo'l orqali dunyodagi millionlab odamlarga yetib boradi.

Talabalar ko'p adashadigan joy

Ko'p talabalar «Domen» va «IP manzil»ni bir xil narsa deb o'ylashadi. Ta'kidlab o'tamiz: Domen — bu odam uchun qulay ism, IP — bu kompyuter tushunadigan haqiqiy manzil, DNS esa ikkovini bir-biriga bog'lovchi «tarjimon». Buni keyingi slaydda batafsil ko'ramiz.

Reja 1 · Nazariya

IP manzil, Domen va DNS

Internetdagi har bir qurilma (kompyuter, telefon, server) o'ziga xos raqamli manzilga ega — xuddi har bir uyning pochta manzili bo'lgani kabi.

TushunchaMisolMa'nosi
IP manzil (IP Address)172.217.16.142Qurilmaning tarmoqdagi haqiqiy, raqamli manzili.
Domen (Domain)google.comOdam eslab qolishi oson bo'lgan, o'qiladigan nom.
DNS (Domain Name System)«google.com → 172.217.16.142»Domen nomini IP manzilga aylantiruvchi tizim — internetning telefon kitobi.
Oddiy tilda

Siz brauzerga google.com deb yozganingizda, DNS tizimi orqaga «bu domenning haqiqiy IP manzili shu» deb javob beradi, shundan keyingina brauzer to'g'ri serverga ulanadi. Odamlar raqamlarni eslab qolishni yoqtirmaydi — shuning uchun domen nomi o'ylab topilgan.

Reja 1 · Nazariya

Provider (ISP) va API tushunchalari

📡

Provider (ISP)

Internet Service Provider — bu sizga internetni «yetkazib beruvchi» kompaniya (masalan, Beeline, Uzmobile, TPS). Ular sizning uyingizni katta internet tarmog'iga ulaydi — xuddi suv kompaniyasi uyingizga suv quvurini ulagani kabi.

🔌

API

Application Programming Interface — ikki dastur bir-biri bilan «gaplashishi» uchun kelishilgan qoidalar to'plami. Masalan, ob-havo ilovasi o'zi ob-havoni «bilmaydi», u boshqa serverdan API orqali ma'lumot so'raydi va javobni ko'rsatadi.

Hozircha shu yetarli

Bu tushunchalarga keyingi darslarda qayta-qayta qaytamiz — hozircha faqat umumiy tasavvur kifoya. Muhimi: internet yagona bo'sh tushuncha emas, balki bir nechta aniq qismlardan (qurilma, tarmoq, kompaniya, tizim) tashkil topgan.

Reja 2 · Amaliyot

Muhitni sozlaymiz: VS Code va Chrome

1. VS Code o'rnatish

Kod yozish uchun matn muharriri (kod editor) kerak — biz Visual Studio Code (qisqacha VS Code) dan foydalanamiz, chunki u bepul, tez va deyarli barcha frontend dasturchilar shu bilan ishlaydi.

code.visualstudio.com → Download → o'rnatish. Windows/macOS/Linux uchun bepul.

2. Chrome brauzeri

Bu — bizning HTML sahifalarimizni ko'rish uchun ishlatadigan oyna, ya'ni mijoz (Client) tomonini biz shu yerda ko'ramiz.

3. Papka tuzilishi — eng muhim qism

Kompyuteringizda (Ish stoli yoki Hujjatlar ichida) html-course nomli bitta asosiy papka yarating va har bir dars uchun ichida alohida papkacha oching.

html-course/
  01-dars/
    index.html
  02-dars/

Nega bu muhim: loyihalar tartibsiz bo'lsa, fayllarni topish qiyinlashadi, HTML fayl esa rasm yoki boshqa fayllarga nisbiy yo'l (relative path) orqali murojaat qiladi — shuning uchun tuzilma toza bo'lishi shart.

Talabalar ko'p adashadigan joy

Ko'p talabalar fayllarni Ish stoli bo'ylab tartibsiz sochib tashlaydi yoki papka nomlarida probel va katta harflar ishlatadi (masalan, Mening Loyiham). Tavsiya: papka va fayl nomlarini har doim kichik harflar va tire (-) bilan yozing — bu keyinchalik saytni internetga joylashda muammo tug'dirmaydi.

Reja 3 · Amaliyot

VS Code kengaytmalari (Extensions)

VS Code-ning kuchli tomoni — uni kengaytmalar bilan boyitish mumkinligi. Chap tarafdagi Extensions belgisini bosib (yoki Cmd+Shift+X / Ctrl+Shift+X), qidiruv orqali uchta muhim kengaytmani o'rnatamiz.

KengaytmaNima qiladi
Live ServerHTML faylni brauzerda ochish bilan bir qatorda, faylga o'zgartirish kiritganingizda sahifani avtomatik yangilab turadi. Fayl → saqlash → brauzer o'zi refresh bo'ladi. O'rnatgandan keyin HTML faylga o'ng tugma bosib «Open with Live Server» ni tanlang.
Material Icon ThemePapka va fayllarga chiroyli, rangli ikonkalar qo'shadi — shunda .html, .css, .js fayllarini ko'z bilan tezda farqlash mumkin bo'ladi.
Auto SaveVS Code-ning o'zida bor sozlama, File menyusidan «Auto Save» ni yoqish orqali faollashtiriladi. Yoqilgandan keyin har safar Ctrl+S bosish shart bo'lmaydi — fayl o'zgarishlar bilan avtomatik saqlanadi.
// Auto Save qo'lda yozilsa shunday ko'rinadi
{
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000
}
Talabalar ko'p adashadigan joy

Ba'zi talabalar Live Server o'rniga HTML faylni to'g'ridan-to'g'ri ikki marta bosib (double-click) ochadi. Bu ham ishlaydi, lekin har safar o'zgarish kiritganda qo'lda F5 bosish kerak bo'ladi — shuning uchun Live Server-dan foydalanishni doim odat qiling.

Reja 4 · Nazariya

HTML nima? Juft va toq taglar

HTML (HyperText Markup Language) — bu dasturlash tili emas, belgilash (markup) tili, ya'ni u sahifaning mazmuni va tuzilmasini belgilaydi. Har bir HTML element — teg (tag) deb ataladi va qavs ichida yoziladi: <teg-nomi>.

Juft taglar (paired)

Ochuvchi va yopuvchi qismdan iborat: <p>matn</p>. Yopuvchi tagda qo'shimcha slash (/) belgisi bo'ladi.

Toq taglar (unpaired)

Yopuvchi juftlik talab qilmaydi, masalan <br> (qator ko'chirish) yoki <hr> (chiziq).

Reja 4 · Nazariya

Sarlavhalar (h1–h6), paragraf (p) va br

Sarlavha taglarini gazeta bilan solishtiring: gazetaning bosh sahifasidagi katta sarlavha — h1, kichikroq bo'lim nomlari — h2, h3 va hokazo.

<h1>–<h6> — sarlavhalar

h1 — eng katta va eng muhim sarlavha (odatda sahifada bitta bo'ladi), h6 — eng kichigi.

<p> — paragraf

Oddiy matn bo'lagi, xatboshi uchun ishlatiladi.

<br> — qator ko'chirish

Xatboshi ochmasdan, faqat qatorni yangi qatorga ko'chiradi — masalan, she'r yozayotganda yoki manzilni bir necha qatorga bo'lib yozayotganda.

<h1>Salom, men Aziz</h1>
<h2>Frontend dasturchi bo'lishga intilyapman</h2>
<p>Men hozirda HTML va CSS o'rganyapman.</p>
<p>
  Manzilim:<br>
  Toshkent shahri,<br>
  Chilonzor tumani
</p>
Talabalar ko'p adashadigan joy

Ko'pchilik yopuvchi tagni yozishni unutadi (masalan, <p>matn deb yozib, </p> qo'ymaydi) yoki h1 ni sahifada bir necha marta ishlatib yuboradi. h1 — sahifada faqat bitta bo'lishi tavsiya etiladi, chunki u sahifaning asosiy mavzusini bildiradi.

Amaliy vazifa

Uyga vazifa: vizitka-sahifa (bio-page)

1 O'zingiz haqingizda vizitka-sahifa yarating

  1. Kompyuteringizda 01-dars nomli papka yarating (kichik harf, defis bilan).
  2. Ichida index.html faylini yarating.
  3. Bitta <h1> — ism-familiyangiz.
  4. Bitta <h2> — kasb yoki maqsad (masalan, «Bo'lajak frontend dasturchi»).
  5. Kamida uchta <p> — o'zingiz haqingizda: qayerdansiz, nima bilan qiziqasiz, nima uchun dasturlashni o'rganmoqchisiz.
  6. Kamida bir joyda <br> ishlating (masalan, manzil yoki kontakt ma'lumotida).
  7. Live Server orqali oching va brauzerda tekshiring.
Baholash mezoni: fayl index.html nomida, o'z 01-dars papkasida saqlangan · kamida bitta h1, bitta h2 va uchta p ishlatilgan · kamida bir joyda br bor · barcha taglar yopilgan · sahifa Live Server orqali ochilganda xatosiz ko'rinadi.
Diqqat

Bu sahifada faqat sarlavhalar (h1, h2, h3) va paragraflar (p) bo'lishi kerak — hech qanday rasm yoki boshqa teglar shart emas, chunki biz hali HTML-ning eng boshlang'ich qismini o'rgandik. Rasm, havola va ro'yxatlar haqida keyingi darsda gaplashamiz.

Savol-javob

1. Client-Server modelida brauzer va server qanday rol o'ynaydi?

Brauzer — mijoz (Client), u serverga so'rov (request) yuboradi. Server esa so'ralgan HTML faylni javob (response) sifatida qaytaradi. Xuddi restoranda mijoz va oshxona kabi.

2. Domen va IP manzil o'rtasidagi farq nima?

IP manzil — qurilmaning tarmoqdagi haqiqiy, raqamli manzili (masalan 172.217.16.142). Domen — odam eslab qolishi oson bo'lgan nom (masalan google.com). DNS ikkovini bog'lab beradi.

3. Live Server kengaytmasi nima uchun kerak?

Fayl saqlanganda brauzerni avtomatik yangilaydi, shuning uchun har safar qo'lda F5 bosish shart bo'lmaydi. Bu ishni sezilarli tezlashtiradi.

4. Qaysi teglar toq (yopilmaydigan) hisoblanadi? Ikkitasini ayting.

<br> (qator ko'chirish) va <hr> (gorizontal chiziq). Ularning ichida kontent bo'lmagani uchun yopilish tegi kerak emas.

5. Nega sahifada faqat bitta <h1> bo'lishi tavsiya etiladi?

Chunki h1 sahifaning asosiy mavzusini (eng muhim sarlavhasini) bildiradi. Bir nechta h1 ishlatish sahifaning mazmun tuzilmasini chalkashtirib yuboradi.
