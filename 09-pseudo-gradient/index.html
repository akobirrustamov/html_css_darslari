Savol

Reja 1 · Holat psevdo-klasslari

:hover, :active, :focus — elementning «hayoti»

Eng ko'p ishlatiladigan uchta holat psevdo-klassi bor. :hover — sichqoncha element ustiga kelganda ishga tushadi, masalan tugma rangi o'zgarishi. :active — sichqoncha tugmasini bosib, hali qo'yib yubormagan aniq lahzadagi holat — odatda tugma biroz «botib» ketganday ko'rinadi, bu foydalanuvchiga «bosilmoqda» degan tuyg'u beradi. :focus esa element klaviatura (Tab) yoki bosish orqali «faollashtirilganda» ishga tushadi — bu ayniqsa klaviatura orqali saytdan foydalanadigan odamlar uchun juda muhim, chunki ular qaysi elementda turganini ko'rishlari kerak.

.btn {
  padding: 12px 24px;
  background: #4a6cf7;
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
}

.btn:hover {
  background: #3a56d4;
}

.btn:active {
  background: #2f46b0;
}

.btn:focus {
  outline: 3px solid #a3b8ff;
}
Ko'p uchraydigan xato

Ko'pchilik :focusni umuman e'tiborsiz qoldiradi yoki outline: none; deb o'chirib qo'yadi — bu klaviatura bilan foydalanuvchilar uchun saytni «ko'rmas» qilib qo'yadi. Agar outline'ni o'chirsangiz, albatta o'rniga boshqa ko'rinadigan stil (masalan border yoki box-shadow) qo'ying.

Reja 1 · Struktura psevdo-klasslari

:first-child, :last-child, :nth-child()

Tasavvur qiling — sizda menyu bor va oxirgi elementdan keyin chiziq chizilmasligi kerak, faqat oldingilaridan keyin bo'lsin. Aynan shu joyda :last-child yordam beradi — «menga class kerak emas, sen ro'yxatdagi oxirgi element ekaningni CSS o'zi bilib oladi» deymiz. Xuddi shunday :first-child — ro'yxatdagi birinchi elementga. Eng kuchlisi — :nth-child(): qavs ichiga raqam yoki formula yozib, masalan har 2-elementni tanlash mumkin — jadvalda qator-qator rang berish uchun juda mashhur usul, «zebra» effekt deb ataladi.

Pseudo-klassQachon ishga tushadiQayerda foydali
:first-childOta ichidagi birinchi elementRo'yxat boshini boshqacha stillash
:last-childOta ichidagi oxirgi elementOxirgi elementdan ortiqcha chegarani olib tashlash
:nth-child(n)n-tartibdagi element; formula ham bo'ladinth-child(2n) — jadvalda «zebra» qatorlar (juft)
:nth-child(odd)Toq tartibdagi elementlar: 1, 3, 5...2n+1 bilan bir xil natija
Formula qanday o'qiladi

nth-child(2n) — juft elementlar (2, 4, 6...). nth-child(odd) yoki nth-child(2n+1) — toq elementlar (1, 3, 5...). nth-child(3) — aynan uchinchi element, formula shart emas.

Adashtirmaslik kerak

:nth-child() — bu ota-ona ichidagi elementning tartib raqami, «shu turdagi elementning nechinchisi» emas (u uchun :nth-of-type() bor). Ota ichida turli xil teglar aralash bo'lsa, bu ikkisi boshqa-boshqa natija berishi mumkin.

Reja 2 · Pseudo-elementlar

::before va ::after: HTML'ga tegmasdan bezak qo'shish

Ba'zan dizaynda dekorativ narsa kerak bo'ladi — masalan sarlavha oldida kichkina belgi, yoki kartochka burchagida «Yangi» yorlig'i. Buni HTML'ga qo'shimcha <span> yozib ham qilsa bo'ladi, lekin bu — sof dizayn uchun HTML'ni «iflos» qiladi, chunki bu elementning hech qanday mazmuni yo'q, faqat ko'rinish uchun. Shuning uchun CSS'ning o'ziga «sen mendan avval yoki keyin qo'shimcha bir narsa yasab qo'y» deymiz: ::before element mazmunidan OLDIN, ::after esa mazmundan KEYIN «virtual» element yasaydi.

Majburiy shart: content

Ishlashi uchun content xossasi albatta yozilishi shart — hatto bo'sh qiymat (content: "";) bo'lsa ham. Aks holda pseudo-element umuman ko'rinmaydi.

.title::before {
  content: "★ ";
  color: #f5a623;
}

Misol: kartochka burchagidagi yorliq

HTML'ga qo'lda «Yangi» yozuvi qo'shish o'rniga, kartochkaga bitta CSS qoidasi bilan avtomatik yorliq qo'shamiz.

.card {
  position: relative;
}

.card::after {
  content: "Yangi";
  position: absolute;
  top: -10px;
  right: -10px;
  background: #ff4757;
  color: white;
  font-size: 12px;
  padding: 4px 10px;
  border-radius: 20px;
}
Eng ko'p uchraydigan xato

content: "";ni unutib qoldirish — natijada boshqa hamma CSS to'g'ri yozilgan bo'lsa ham, pseudo-element sahifada umuman ko'rinmaydi, chunki brauzer uni «bo'sh, demak ko'rsatmayman» deb hisoblaydi.

Reja 3 · Gradientlar

linear-gradient(): fon va tugmalar uchun rang o'tishi

Bitta tekis rang o'rniga ikkita yoki undan ko'p rangning bir-biriga silliq o'tishini xohlasak — linear-gradient() funksiyasi ishlatiladi. Unga yo'nalish (masalan to right, 45deg) va ranglar ro'yxati beriladi. Bu funksiya nafaqat fon uchun, balki tugmalarga zamonaviy ko'rinish berish uchun ham juda ko'p ishlatiladi.

.gradient-btn {
  padding: 14px 28px;
  border: none;
  border-radius: 8px;
  color: white;
  font-weight: bold;
  background: linear-gradient(to right, #ff6a00, #ee0979);
}
Yo'nalishNatija
to rightChapdan o'ngga o'tish
to bottomYuqoridan pastga o'tish (standart yo'nalish)
45degAniq gradus bo'yicha diagonal o'tish
linear-gradient(to right, red, yellow, green)Ikkitadan ortiq rang — bir nechta o'tish nuqtasi
Maslahat

Odatda 2-3 tadan ortiq rang ishlatilmaydi — aks holda gradient «iflos» va tartibsiz ko'rinadi.

Reja 3 · Rasm ustiga overlay

Rasm ustiga gradient overlay: matnni o'qiladigan qilish

Agar orqa fonda rasm bo'lib, uning ustiga matn yozish kerak bo'lsa, matn o'qilishi qiyinlashadi. Shuning uchun rasm ustiga yarim shaffof gradient «qatlam» (overlay) qo'yiladi — bu background-image ichida ikkita qiymatni vergul bilan yozib, gradientni rasmdan OLDIN ko'rsatish orqali qilinadi (birinchi qatlam tepada chiqadi).

.hero {
  height: 300px;
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.5)),
    url("hero.jpg");
  background-size: cover;
  background-position: center;
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
}
Ko'p uchraydigan xato

background-image ichida gradient va url() yozilganda tartib muhim — gradient birinchi yozilsa, u rasm USTIDA ko'rinadi (chunki CSS'da birinchi qatlam eng tepada chiqadi). Rasm «nega ko'rinmayapti» degan savol tug'ilsa — javob: rangni shaffofroq (masalan 0.5 emas, 0.9dan kam) qilib qo'yish kerak.

Best practice

Yaxshi amaliyot — qisqacha

  • Har doim :focus uchun ko'rinadigan stil qoldiring — foydalanuvchi klaviatura bilan yurganida ko'rishi kerak.
  • ::before/::afterga albatta content yozing, hatto bo'sh bo'lsa ham.
  • :nth-child()ni avval oddiy holatlarda (odd/even) sinab ko'ring, keyin murakkab formulaga o'ting.
  • Gradientda 2-3 tadan ortiq rang ishlatmang — oshib ketsa dizayn «iflos» ko'rinadi.
  • Rasm ustiga matn qo'yishda har doim gradient overlay qo'shing va matn kontrastini tekshiring.
Keyingi qadam — silliqlik

Bugun qo'lda qurgan hover effektlari, pseudo-elementlar va gradientlar — hammasi hozircha «statik» sodir bo'ladi. Keyingi modulda aynan shu effektlarni transition va transform bilan jonli, silliq animatsiyaga aylantiramiz.

Savol-javob

1. :hover va :active orasidagi farq nima?

:hover sichqoncha element ustida turgan har qanday paytda ishlaydi. :active esa faqat sichqoncha tugmasi bosilib, hali qo'yib yuborilmagan aniq lahzada ishlaydi — bosilish tugagach, holat :hoverga qaytadi.

2. Nega :focusni outline: none; bilan o'chirib qo'yish xato hisoblanadi?

Chunki klaviatura orqali (Tab bilan) saytdan foydalanuvchilar qaysi elementda turganini faqat shu vizual belgi orqali bilishadi. Outline'ni o'chirsangiz, o'rniga boshqa ko'rinadigan stil (border, box-shadow) qo'yish shart.

3. ::before/::after ishlashi uchun qaysi xossa majburiy?

content xossasi — hatto content: ""; kabi bo'sh qiymat bo'lsa ham albatta yozilishi kerak. Aks holda brauzer pseudo-elementni umuman ko'rsatmaydi.

4. nth-child(2n) qaysi elementlarni tanlaydi?

Juft tartib raqamli elementlarni: 2, 4, 6... Toq elementlar uchun nth-child(odd) yoki nth-child(2n+1) ishlatiladi. Bu ko'pincha ro'yxatlarda «zebra» qatorlar yasashda qo'llaniladi.

5. Rasm fon ustiga matn yozilganda o'qilishi qiyin bo'lsa, qanday yechim bor va u qanday yoziladi?

Gradient overlay qo'shiladi: background-imageda vergul bilan avval yarim shaffof linear-gradient(rgba(...), rgba(...)), keyin url("rasm.jpg") yoziladi — birinchi yozilgan qatlam rasm ustida chiqadi.
