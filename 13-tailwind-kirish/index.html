Tailwind CSS'ga
kirish va sozlash

12-modulda siz SASS/SCSS bilan CSS yozishni tezlashtirishni o'rgandingiz — o'zgaruvchilar, nesting, mixin. Lekin ikkala fayl (HTML va stil fayli) orasida sakrash hali ham qolgan edi. Bugun esa butunlay boshqa yondashuvga o'tamiz: Tailwind CSS — stillarni to'g'ridan-to'g'ri HTML ichida, tayyor kichik classlar orqali yozish usuli.

Maqsad

Dars oxirida siz nima qila olasiz

Video oxirida siz Tailwind CSS'ni CDN orqali loyihaga ulab, spacing, typography, rang, flexbox va grid utility classlari yordamida oddiy komponentni alohida CSS fayl yozmasdan stillay olasiz.

⚡

Tezroq stillaysiz

CSS fayl bilan HTML fayl o'rtasida sakramasdan, to'g'ridan-to'g'ri class yozib natijani darhol ko'rasiz.

🧱

Tayyor "g'isht" classlar

p-6, rounded-xl, bg-blue-500 — har biri bitta CSS xususiyatini bajaradigan kichik utility class.

🧩

Yangi layout tushunchalari

flex va grid — bu darsda birinchi marta ko'radigan, sahifani qatorga yoki katakchalarga bo'lib joylashtirish usullari.

🛍️

Real komponent qurasiz

Hero-section va mahsulot kartochkasi — har bir saytda uchraydigan ikkita komponentni Tailwind bilan yasaysiz.

Muhim eslatma

Tailwind sizga yangi CSS o'rgatmaydi — u allaqachon bilgan CSS xususiyatlaringiz (padding, rang, border-radius)ning qisqa yozuv shakli, xolos.

Reja 1 · Nazariya

Utility-first konsepsiyasi nima?

Savol: SCSS'da karta komponenti uchun nima yozgan edik? Javob — avval HTML'ga class="karta" beramiz, keyin alohida faylga o'tib .karta { padding: 24px; border-radius: 12px; } deb yozamiz. Tailwind CSS — bu boshqacha falsafaga asoslangan CSS kutubxonasi: u tayyor komponentlar (Bootstrap kabi tayyor tugma yoki navbar dizayni) bermaydi, balki har biri bitta CSS xususiyatini bajaradigan kichik utility classlar beradi — xuddi LEGO konstruktoridagi kichik detallar kabi, uyni o'zingiz qurib chiqasiz.

An'anaviy usul (SCSS, 12-modul)

<div class="karta">...</div>
.karta {
  padding: 24px;
  border-radius: 12px;
  background: #ffffff;
}

Ikkita fayl, o'zingiz o'ylab topgan class nomi, har bir xususiyat alohida qatorda.

Utility-first (Tailwind)

<div class="p-6 rounded-xl bg-white">
  ...
</div>

Bitta fayl, class nomini o'ylab topish shart emas — p-6 = padding, rounded-xl = border-radius, bg-white = background. Alohida CSS fayl umuman kerak emas.

Talabalar ko'p adashadigan joy

Ko'p talaba Tailwind'ni "tayyor dizayn kutubxonasi" deb o'ylaydi va tayyor tugma yoki navbar qidiradi. Aslida Tailwind faqat CSS xususiyatlarining qisqa yozuvi — dizaynni hamon o'zingiz bilgan CSS bilimingiz asosida quriysiz.

Reja 1 · Taqqoslash

Sof CSS va Tailwind — bir xil natija

Quyidagi ikkala kod ham xuddi bir xil natija beradi: 24px padding va 12px burchak yumaloqligi bo'lgan quti. Farq faqat qayerda va qanday yozilishida.

SOF CSS — alohida fayl kerak
.card {
  padding: 24px;
  border-radius: 12px;
}
<div class="card">...</div>
TAILWIND — bitta qatorda, HTML ichida
<div class="p-6 rounded-xl">
  ...
</div>
Bu CSS'ning "yomon" ekanini anglatmaydi

Sof CSS to'liq to'g'ri va ba'zan yagona to'g'ri yechim (masalan murakkab animatsiya yoki noyob dizayn uchun). Tailwind faqat tez-tez takrorlanadigan, oddiy stillash uchun vaqtni qisqartiradi. p-6 nega aynan 24px berayotgani — keyingi slaydlarda ko'ramiz.

Reja 1 · Afzalliklar

Nega Tailwind bunchalik mashhur

🚀

Tezlik

Stil yozish uchun boshqa faylga o'tish, class nomi o'ylab topish, keyin qaytib kelish shart emas — hammasi bitta joyda, HTML ichida.

📏

Konsistentlik

Spacing (4, 8, 16, 24...) va rang skalasi loyiha bo'ylab oldindan belgilangan. Bir dizaynerning "13px", boshqasining "17px" degan tasodifiy sonlari yo'qoladi.

🧹

Kerakmas CSS yo'q

Real loyihada build jarayoni sahifada ishlatilmagan classlarni yakuniy faylga umuman qo'shmaydi — natijada CSS fayl juda kichik bo'ladi.

Bitta eslatma

Yuqoridagi "ishlatilmagan CSS'ni olib tashlash" — bu build jarayoni (npm + Vite yoki shunga o'xshash vosita) orqali ishlaydi. Bugun biz oddiyroq — CDN — usulidan foydalanamiz, build jarayoni haqida keyingi slaydda bir og'iz gapiramiz.

Reja 2 · Sozlash

Tailwind CSS'ni CDN orqali loyihaga ulash

Tailwind'ni ishlatishning eng tez yo'li — <head> ichiga bitta <script> qatorini qo'shish. Bu — CDN (Content Delivery Network, tayyor kutubxonani internetdan to'g'ridan-to'g'ri ulash xizmati) usuli. Hech qanday o'rnatish, hech qanday terminal buyrug'i kerak emas.

<!doctype html>
<html lang="uz">
<head>
  <meta charset="utf-8">
  <title>Sahifam</title>
  <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
</head>
<body>
  <h1 class="text-3xl font-bold text-blue-600">Ishladi!</h1>
</body>
</html>
Bugun aynan shu usuldan foydalanamiz

CDN usuli — o'quv va tezkor prototip maqsadlari uchun to'liq yetarli. Bu darsdagi jonli mashq ham aynan shu <script> orqali ishlaydi.

Talabalar ko'p adashadigan joy

<script> tegini <body> ichiga yoki fayl oxiriga qo'yib qo'yishadi — natijada birinchi render paytida stillar "yalang'och" HTML ko'rinishida bir lahza miltillab ko'rinadi. Har doim <head> ichiga, va imkon qadar yuqoriroqqa qo'ying.

Real loyihada esa

Katta, jiddiy loyihalarda odatda npm orqali o'rnatiladigan va build (Vite, PostCSS) jarayonidan o'tadigan Tailwind ishlatiladi — bu ishlatilmagan classlarni avtomatik olib tashlaydi va yakuniy fayl hajmini kichraytiradi. Bu kursda bunga chuqurlashmaymiz, faqat borligini bilib qo'ying.

Ranglar tizimi — tayyor palitradan foydalanish

Har bir rang {rang}-{ottenka} ko'rinishida yoziladi: ottenka 50 (eng ochiq) dan 950 (eng to'q) gacha. Odatda 500 — o'sha rangning "asosiy" varianti.

</div>

Loyihada bitta dizayner #3B82F6, boshqasi #3A80F5 ishlatsa — ko'zga bilinmas, lekin natijada rang mos kelmay qoladi. Tayyor palitra bilan butun jamoa bir xil blue-500ni ishlatadi — natija har doim konsistent.

Reja 4 · Yangi tushuncha

Flexbox — bir yo'nalishli joylashuv

Siz hali flexbox bo'yicha alohida dars ko'rmagansiz — shuning uchun avval tushunchani tushuntiramiz. Flexbox — elementlarni bitta yo'nalish (qator yoki ustun) bo'yicha tekislash va joylashtirish usuli: konteynerga display: flex berilsa, uning ichidagi barcha elementlar avtomatik bir qatorga tizilib, oralaridagi masofani va tekislanishni siz boshqarasiz. Tailwind'da bu xususiyat class nomi sifatida yoziladi: display: flex → flex, justify-content: space-between → justify-between, align-items: center → items-center.

<div class="flex justify-between items-center p-4">
  <span class="font-bold text-lg">Logo</span>
  <button class="bg-blue-600 text-white px-4 py-2 rounded-lg">
    Kirish
  </button>
</div>
ClassSof CSS ekvivalenti
flexdisplay: flex;
justify-betweenjustify-content: space-between;
justify-centerjustify-content: center;
items-centeralign-items: center;
flex-colflex-direction: column;
Talabalar ko'p adashadigan joy

flex classini qo'shmasdan to'g'ridan-to'g'ri justify-between yozishadi — justify-between faqat konteynerga flex yoki grid berilgan bo'lsa ishlaydi, aks holda hech narsa o'zgarmaydi.

Reja 4 · Yangi tushuncha

Grid — qator va ustunlarga bo'lingan joylashuv

Grid — flexbox'dan farqli o'laroq, elementlarni bir vaqtning o'zida qator ham, ustun ham bo'yicha, ikki o'lchamli katakchalar (jadval) shaklida joylashtirish usuli — masalan mahsulot kartochkalarini teng ustunlarga bo'lib chiqish uchun juda qulay. Konteynerga display: grid berilib, ustunlar soni grid-template-columns orqali belgilanadi.

<div class="grid grid-cols-3 gap-4">
  <div class="col-span-2 bg-gray-100 p-4 rounded-lg">Keng ustun</div>
  <div class="bg-gray-100 p-4 rounded-lg">Tor ustun</div>
</div>
ClassSof CSS ekvivalenti
griddisplay: grid;
grid-cols-3grid-template-columns: repeat(3, 1fr);
col-span-2grid-column: span 2;
gap-4gap: 16px;
Reja 4 · Qaror

Flex yoki Grid — qaysi birini tanlash?

Flexbox — bir yo'nalish (1D)

Navbar, tugmalar qatori, elementni markazga tekislash — barchasi bitta chiziq bo'ylab joylashadi. Ishlatiladigan class: flex.

Grid — qator + ustun (2D)

Mahsulot kartochkalari, galereya, sahifa layout'i — elementlar ikki o'lchamli katakchalarga teng bo'lib joylashadi. Ishlatiladigan class: grid.

Hech narsa yangi emas — faqat yozuv shakli

Agar keyinchalik sof CSS'da display: flex yoki display: grid ni chuqur o'rgansangiz — bu ikki slayd sizga faqat Tailwind'dagi class nomlarini ko'rsatdi, mantiq bir xil qoladi.

Best practice

Yaxshi amaliyot — qisqacha

  • Aksariyat holatda standart spacing va rang skalasidan foydalaning — bu konsistentlikni saqlaydi.
  • Classlarni o'qilishi oson bo'lishi uchun mantiqiy tartibda yozing: layout (flex/grid) → spacing → rang → border/shadow.
  • flex yoki gridni yozishni unutmang — ular bo'lmasa ichki utility'lar ishlamaydi.
  • CDN scriptni har doim <head> ichiga, eng boshiga qo'ying.
  • Sof CSS bilimingizni unutmang — Tailwind faqat uning ustiga qurilgan qisqa yozuv, asos hamon CSS.
Keyingi qadam

Keyingi darsda bu classlarni ekranga qarab o'zgartirishni — responsive prefikslar (sm:, md:, lg:), hover/focus holatlari va arbitrary values sintaksisini chuqurroq ko'ramiz. Sahifangiz nafaqat chiroyli, balki har qanday qurilmada mukammal ko'rinadigan bo'ladi.

Amaliy vazifa

Uyga vazifa: Hero-section va Card komponenti

Tailwind CSS yordamida tezkor Hero-section va Card komponentini yarating. Yangi HTML fayl oching, <head> ichiga bugun ko'rgan Tailwind CDN scriptini qo'ying.

1 Hero-section

  1. Katta sarlavha yozing — text-3xl font-bold.
  2. Qisqa tavsif matni qo'shing — text-gray-500.
  3. Bitta tugma qo'shing — bg-blue-600 text-white px-6 py-3 rounded-lg.
  4. Hammasini flex flex-col items-center bilan vertikal markazlashtiring, atrofiga py-16 bering.

2 Card komponenti

  1. Har bir kartani bg-white rounded-xl shadow-md p-6 asosida quring.
  2. Ichiga sarlavha (<h3>) va qisqa matn qo'shing.
  3. Kamida 3 ta shunday kartani grid grid-cols-3 gap-4 bilan joylashtiring.
Baholash mezoni: alohida CSS fayl yozilmagan · Hero-section markazlashgan va padding to'g'ri berilgan · kamida 3 ta karta grid orqali teng joylashgan · har bir kartada padding, rounded va shadow classlari mavjud · rang va typography classlari mos ishlatilgan.

Savol-javob

1. "Utility-first" yondashuvi nima degani?

Alohida CSS fayl yozib, o'zi o'ylab topilgan class nomiga stil berish o'rniga, HTML ichida har biri bitta CSS xususiyatini bajaradigan kichik, tayyor classlardan (utility) foydalanish. Masalan p-6, flex, rounded-xl.

2. p-4 necha piksel padding beradi va nega aynan shuncha?

16px. Tailwind'ning spacing skalasida har bir son 0.25rem (4px)ga ko'paytiriladi: 4 × 4px = 16px.

3. Nega text-blue deb yozish ishlamaydi?

Chunki Tailwind'da rang classlari {rang}-{ottenka} ko'rinishida yoziladi — ottenka (masalan -500) majburiy qism. To'g'ri yozuv: text-blue-500.

4. Konteynerga flex yozmasdan, faqat justify-between yozilsa nima bo'ladi?

Hech narsa o'zgarmaydi. justify-between (va shunga o'xshash boshqa flex/grid utility'lar) faqat konteynerga display: flex yoki display: grid berilgan bo'lsa ishlaydi.

5. Tailwind CDN scriptini qayerga qo'yish kerak va nega?

<head> ichiga, imkon qadar yuqoriroqqa. Aks holda, script <body> oxirida yoki kech yuklansa, sahifa birinchi ochilganda "yalang'och" (stilsiz) HTML bir lahza ko'rinib, keyin stillanadi.
