05-modul

CSS Ranglar va O'lchamlar:
sahifangizga aniq shakl bering

Tasavvur qiling: dizayner sizga tugmaning rangini #3498db deb yubordi, lekin siz faqat red, blue kabi nomli ranglarni bilasiz. Yoki elementga width: 300px berdingiz — kompyuterda chiroyli, telefonda esa ekrandan chiqib ketyapti. Bugun ikkala muammoni ham hal qilamiz.

Maqsad

Dars oxirida siz nima qila olasiz

Bu darsdan keyin siz CSS'da rangni to'rt xil usulda (nomli, HEX, RGB, RGBA) bera olasiz va kontekstga qarab to'g'ri o'lchov birligini (px, %, em, rem, vh, vw) tanlab ishlata olasiz.

🎨

Ranglaysiz

Nomli rang, HEX va RGB — bir xil rangni yozishning uch xil usulini.

🔍

Shaffof qilasiz

rgba() yordamida yarim shaffof fon va qoplamalar yasashni.

📏

O'lchaysiz

px, %, em, rem orasidagi farqni va qachon qaysi birini ishlatishni.

📱

Moslashtirasiz

vh/vw bilan butun ekranni egallovchi bo'limlar yasashni.

Bu darsning tuzilishi

Avval ranglarni, keyin o'lchamlarni ko'ramiz. Ikkalasida ham jonli mashq bor — qiymatni o'zgartiring, natijani darhol ko'ring.

Reja 1 · Nazariya

Ranglarni CSS'da qanday yozamiz

CSS'da rangni bir nechta usulda ko'rsatish mumkin, va har birining o'z o'rni bor. Birinchi ikkitasi — eng oddiylari.

FormatYozilishiIzoh
Nomli (keyword)red, blue, orangeTaxminan 140 ta oldindan tayyor nom. Eng oson usul, lekin aniq soyani (masalan «biroz to'qroq ko'k») tanlay olmaysiz.
HEX#RRGGBB, masalan #3498dbDizaynerlar deyarli har doim shu formatda beradi. #dan keyin 6 ta belgi: birinchi ikkitasi qizil (Red), keyingisi yashil (Green), oxirgisi ko'k (Blue) — 00dan FFgacha (16-lik sanoq sistemasida 0–255).
Analogiya

Har qanday rang aslida uchta lampaning — qizil, yashil, ko'k lampaning — turli quvvatda yonishidan hosil bo'ladi. Barchasi to'liq yonsa — oq, barchasi o'chiq bo'lsa — qora rang chiqadi.

.card-red {
  background-color: red; /* keyword - nomli rang */
}

.card-hex {
  background-color: #3498db; /* HEX - dizaynerlar shu formatda beradi */
}
Ko'p adashiladigan joy

HEX kodda # belgisini yozishni unutib qo'yishadi — background-color: 3498db; ishlamaydi, chunki bu son emas, rang kodi ekanini brauzer #siz tushunmaydi.

Reja 1 · Asosiy

RGB va RGBA — sonlar bilan rang berish

Uchinchisi — RGB format: xuddi HEX'dagi tamoyil, lekin o'nlik sonlar bilan yoziladi. To'rtinchisi — RGBA: RGB'ga to'rtinchi parametr, alpha (shaffoflik), qo'shiladi.

FormatYozilishiIzoh
RGBrgb(52, 152, 219)Qizil, yashil, ko'k — har biri 0–255 oralig'ida. HEX bilan RGB — bir xil rangni ikki xil yozish usuli, xolos.
RGBArgba(52, 152, 219, 0.5)To'rtinchi qiymat — alpha: 0 (butunlay ko'rinmas) dan 1 (to'liq tiniq) gacha. Overlay effektlar, shaffof fonlar yasashda ko'p ishlatiladi.
.card-rgb {
  background-color: rgb(52, 152, 219); /* xuddi #3498db, boshqa yozuv */
}

.card-rgba {
  background-color: rgba(52, 152, 219, 0.5); /* 50% shaffof */
}
Ko'p adashiladigan joy

RGB'da qavs ichidagi ranglar tartibini chalkashtirib yuborishadi — tartib doim qizil, yashil, ko'k (R, G, B). Shuningdek rgba()ga faqat 3 ta qiymat berib, alphani unutib qo'yishadi — natijada shaffoflik ishlamaydi.

Jonli mashq

RGBA bilan shaffoflikni sinab ko'ring

Pastda to'rtta kartochka — nomli, HEX, RGB va RGBA rangda. rgba() dagi oxirgi sonni (0 dan 1 gacha) o'zgartirib, shaffoflik qanday ishlashini kuzating.

ranglar.html
Sinab ko'ring

rgba(52, 152, 219, 0.5) dagi 0.5 ni 0.1 ga o'zgartiring — kartochka orqa fonga (#eef0f7) deyarli qo'shilib ketadi. 1 ga o'zgartirsangiz — .card-rgb bilan bir xil to'liq tiniq rangga aylanadi.

Reja 2 · Nazariya

O'lcham birliklari: px va %

Rangni o'rgandik, endi element qanchalik katta bo'lishini ham ko'rsatish kerak. Buning uchun turli o'lchov birliklari bor, va har birining o'z vazifasi bor.

BirlikNimaga nisbatan hisoblanadiIzoh
px (piksel)Hech nimaga — mutlaq (absolute) qiymatEng oddiy birlik, ekrandagi aniq nuqta. Muammosi: barcha qurilmalarda bir xil o'lchamda qoladi, ya'ni moslashuvchan (responsive) emas.
% (foiz)Ota elementga (parent)width: 50% — ota elementning yarmini egallaydi. Ota element o'zgarsa, bola ham avtomatik moslashadi.
html {
  font-size: 16px; /* rem shu songa asoslanib hisoblanadi */
}

.box-px {
  width: 300px; /* mutlaq, hamma joyda bir xil */
}

.box-percent {
  width: 50%; /* ota elementning yarmi */
}
Reja 2 · Davomi

O'lcham birliklari: em va rem

em va rem ikkalasi ham shriftga bog'liq "lineyka" sifatida ishlaydi, lekin bir-biridan muhim jihati bilan farq qiladi.

BirlikNimaga nisbatan hisoblanadiIzoh
emJoriy elementning shrift o'lchamiga (font-size)1em — joriy font-size bilan teng. Muammosi: ichma-ich (nested) elementlarda bir-biriga qo'shilib, kutilmagan katta yoki kichik o'lchamlar chiqishi mumkin (compounding effect).
rem (root em)Faqat eng tepadagi html elementining shrift o'lchamiga (odatda 16px)Nechta ichma-ich element bo'lishidan qat'i nazar, hisob-kitob har doim bir xil — shuning uchun emga qaraganda ko'proq tavsiya etiladi.
.box-em {
  font-size: 1.5em; /* joriy elementning shrift o'lchamidan 1.5 barobar */
}

.box-rem {
  font-size: 1.5rem; /* root (html) shrift o'lchamidan 1.5 barobar, ya'ni 24px */
}
Ko'p adashiladigan joy

emdan foydalanganda, bitta elementni boshqasining ichiga joylashtirib, natijada kutilganidan ancha katta yoki kichik shrift chiqib qolishi — bu emning nested elementlarda "qo'shilib ketishi" tufayli yuz beradi. Shu sababli katta loyihalarda ko'pincha rem afzal ko'riladi.

Reja 2 · Davomi

Viewport birliklari: vh va vw

vh/vw (viewport height/width) — butun ekran balandligi yoki kengligining foizi. Bu holatda "lineyka" bo'lib ekranning o'zi ishlaydi.

BirlikNimaga nisbatan hisoblanadiIzoh
vhEkran (viewport) balandligining foizi100vh — butun ekran balandligi.
vwEkran (viewport) kengligining foizi100vw — butun ekran kengligi.
.hero {
  width: 100vw;
  height: 100vh; /* butun ekranni egallaydi */
}
Qachon ishlatiladi

Bu, masalan, ekranni to'liq egallovchi katta bo'limlar (hero section) yasashda juda foydali. Oddiy tarzda tushuntirish uchun: em/rem — shriftga bog'liq lineyka, vh/vw esa — ekranning o'zi lineyka bo'lib ishlaydigan birlik.

Jonli mashq

Ranglar va o'lchamlarni birlashtiring

Pastdagi kartochkada kenglik pxda, sarlavha shrifti remda, ichki matn kengligi %da, qoplama esa rgba() bilan berilgan. Qiymatlarni o'zgartirib sinab ko'ring.

kartochka.html
Sinab ko'ring

width: 300px ni width: 90% ga o'zgartiring — brauzer oynasini kichraytirganda karta qanday moslashishini kuzating. So'ng rgba(47, 92, 255, 0.15) dagi oxirgi sonni 0.6 ga oshirib ko'ring.

Xatolar

Ranglar va o'lchamlarda eng ko'p uchraydigan xatolar

XatoNima bo'ladiYechim
HEX'da # unutilgan background-color: 3498db; ishlamaydi HEX qiymat har doim # bilan boshlanishi kerak: #3498db
RGB'da rang tartibi chalkashtiriladi Kutilmagan rang chiqadi Tartib doim: qizil, yashil, ko'k — rgb(R, G, B)
rgba()ga 4-qiymat (alpha) unutiladi Shaffoflik berilmaydi yoki qoida ishlamaydi rgba(r, g, b, alpha) — har doim 4 ta qiymat, oxirgisi 0–1 oralig'ida
em va rem chalkashtiriladi Ichma-ich elementlarda shrift kutilganidan ancha katta/kichik chiqadi Root'ga bog'liq, barqaror hisob kerak bo'lsa — rem ishlating
Hamma joyda faqat px ishlatiladi Sahifa turli ekran o'lchamlarida (masalan telefonda) moslashmay qoladi Kontekstga qarab %, rem, vh/vwdan ham foydalaning
Best practice

Qaysi vaziyatda qaysi birlikni tanlash kerak

✓ TAVSIYA ETILADI
.karta {
  border: 1px solid #dfe3ec; /* px - kichik, qat'iy qiymat */
  width: 90%;                /* % - moslashuvchan kenglik */
}

.karta h3 {
  font-size: 1.5rem;         /* rem - shriftga barqaror */
}

.hero {
  height: 100vh;             /* vh - to'liq ekran bo'limi */
}

Har bir birlik o'z vazifasida: chegara va kichik detallar uchun px, moslashuvchan kengliklar uchun %, shrift ierarxiyasi uchun rem, to'liq ekran bo'limlari uchun vh/vw.

✗ TAVSIYA ETILMAYDI
.karta {
  width: 300px;
  border: 1px solid #dfe3ec;
}

.karta h3 {
  font-size: 24px;
}

.hero {
  height: 800px;
}

Hammasi pxda — kichik ekranda karta ekrandan chiqib ketadi, hero bo'limi esa har bir monitorda boshqacha nisbatda ko'rinadi.

Oltin qoida

O'lchamni tanlashdan oldin savol bering: "bu qiymat ota elementga, shriftga yoki ekranning o'ziga bog'liq bo'lishi kerakmi?" Javobga qarab %, rem yoki vh/vw tanlang — faqat haqiqatan o'zgarmasligi kerak bo'lgan joyda (masalan ingichka chegara chizig'i) px qoldiring.

Amaliy vazifa

Uyga vazifa — vizual kartochkalar

1 Rangli bloklar va matnlardan iborat vizual kartochkalar

  1. Kamida 3 ta kartochka (<div class="karta">) yasang.
  2. Birinchi kartochkada — nomli rang, ikkinchisida — HEX, uchinchisida — RGBA yordamida shaffof overlay ishlatilgan bo'lsin.
  3. Kartochkalarning o'lchamlarini bera turib, kamida 3 xil o'lchov birligidan foydalaning — masalan px bilan kenglik, % bilan ichki matn kengligi, rem bilan shrift o'lchami.
  4. Namuna sifatida darsda ko'rgan kartochkani asos qilib oling: fon rangi HEX'da, sarlavha remda, kartochka kengligi pxda.
Bajarilganlik mezoni: kamida 3 xil rang formati ishlatilganmi (nomli, HEX, RGBA) · kamida 3 xil o'lchov birligi ishlatilganmi (masalan px, %, rem) · kartochkalar brauzer oynasini o'zgartirganda ham buzilmay turadimi.

Savol-javob

O'z-o'zini tekshirish

1. HEX va RGB formatlari o'rtasidagi farq nima?

Aslida farq yo'q — ikkalasi ham bir xil rangni ifodalaydi, faqat yozuv shakli boshqa. HEX 16-lik sanoq sistemasida (#RRGGBB), RGB esa o'nlik sonlar bilan (rgb(R, G, B), har biri 0–255) yoziladi.

2. rgba(52, 152, 219, 0.5) dagi oxirgi 0.5 nimani anglatadi va uni 0 ga o'zgartirsak nima bo'ladi?

Bu — alpha (shaffoflik) qiymati, 0 dan (butunlay ko'rinmas) 1 gacha (to'liq tiniq) bo'ladi. 0 ga o'zgartirilsa, element butunlay ko'rinmas bo'lib qoladi.

3. px bilan % orasidagi asosiy farq nima?

px — mutlaq (absolute) qiymat, hamma qurilmada bir xil o'lchamda qoladi. % esa ota elementga (parent) nisbatan hisoblanadi — ota element o'zgarsa, bola ham avtomatik moslashadi.

4. em nima uchun nested (ichma-ich) elementlarda muammoli bo'lishi mumkin, rem esa yo'q?

em joriy elementning shrift o'lchamiga bog'liq, shuning uchun ichma-ich elementlarda har biri o'zidan oldingi qiymatga "qo'shilib" ketaveradi (compounding effect) — natija kutilmagan bo'lishi mumkin. rem esa har doim faqat html elementining shrift o'lchamiga bog'liq, shuning uchun necha qavat ichma-ich bo'lishidan qat'i nazar hisob bir xil qoladi.

5. Ekranni to'liq egallovchi hero bo'limi uchun qaysi o'lchov birliklari mos keladi?

vh (viewport height) va vw (viewport width). 100vh — butun ekran balandligi, 100vw — butun ekran kengligi, ya'ni ekranning o'zi "lineyka" bo'lib ishlaydi.
