CSS Display moduli:
Block, Inline, Inline-Block va None

<span> elementiga width: 200px va height: 100px berasiz — lekin ekranda hech narsa o'zgarmaydi! Xuddi shu kodni <div>ga bersangiz esa, ajoyib ishlaydi. Nega? Va nega ikkita <div> har doim ustma-ust, alohida qatorda chiqadi — ularni yonma-yon, masalan menyu qilib joylashtirish uchun nima qilish kerak? Bugun buning sirini — CSS'ning display xususiyatini — to'liq ochamiz.

Maqsad

Dars oxirida siz nima qila olasiz

Bu darsdan keyin siz block, inline va inline-block elementlarning xulq-atvoridagi farqni tushunasiz, display: none bilan visibility: hidden orasidagi farqni bilasiz va box-sizing: border-boxdan foydalanib, o'lchamlarni bashorat qilinadigan (predictable) qila olasiz.

🧱

Uchtasini farqlaysiz

block, inline va inline-block — har biri qanday joy egallaydi va width/height ishlaydimi.

👻

Yashirishni tushunasiz

📐

🧭

Bu darsning o'rni

display — deyarli har qanday layout muammosining boshlanish nuqtasi. Element nega kutilganidek joylashmayotganini tushunish uchun avval "bu element tabiatan qanday display'ga ega" savoliga javob berish kerak.

Reja 1 · Nazariya

display: block, inline, inline-block — asosiy farq

Har bir HTML elementi brauzer tomonidan standart bir display turiga ega bo'ladi. Buni analogiya orqali tasavvur qiling: block elementlar — har biri o'z qatorida turadigan kitob bo'limlari kabi; inline elementlar — gap ichidagi alohida so'zlar kabi; inline-block esa — qatorga yozilgan, lekin xohlagan o'lchamda yasash mumkin bo'lgan yorliqlar (stikerlar) kabi.

📚

block

O'z qatorini butunlay egallaydi, undan keyingi element majburan yangi qatordan boshlanadi.

🔤

inline

Faqat o'ziga kerakli joyni egallaydi, xuddi so'z kabi matn ichida oqib turadi.

🏷️

inline-block

Matn qatorida yonma-yon turadi, lekin unga width va height berish mumkin va ular ishlaydi.

Talabalar ko'p adashadigan joy

span yoki a elementiga width/height berib, "nega ishlamayapti" deb ajablanishadi — sababi, bu elementlar standart holda inline, va ularga o'lcham berish uchun avval display: inline-block yoki display: block qilish kerak.

Reja 2 · Nazariya

display: none va visibility: hidden farqi

Ikkalasi ham elementni ko'rinmas qiladi, lekin ular orasida muhim farq bor. Buni shunday tasavvur qiling: display: none — xonadan butunlay chiqib ketish, joy bo'shab qoladi. visibility: hidden esa — ko'rinmas plash kiyib, xonada turishda davom etish, ya'ni joy hali ham band.

Reja 3 · Nazariya

box-sizing: content-box muammosi

Standart holatda (box-sizing: content-box), width/height faqat elementning ichki kontentiga tegishli bo'ladi — padding va border shu o'lchamga QO'SHIB hisoblanadi. Masalan, width: 200px, padding: 20px, border: 5px bo'lsa, elementning haqiqiy (ko'rinadigan) kengligi 200 + 40 (ikki tomondan padding) + 10 (ikki tomondan border) = 250px bo'lib chiqadi.

.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  /* haqiqiy kengligi: 200 + 40 (padding) + 10 (border) = 250px */
}
Bu esa layout yasashda ko'p chalkashlik keltirib chiqaradi

Dasturchi width: 200px deb hisoblaydi, lekin ekranda element 250px kenglikda chiqadi — bu ayniqsa bir nechta ustunni yonma-yon joylashtirganda umumiy kenglikni "sig'dirmay qo'yadi".

Reja 3 · Yechim

box-sizing: border-box — o'lchamlarni bashorat qilinadigan qilish

box-sizing: border-box bilan esa padding va border widthning O'ZI ICHIGA hisoblanadi — element aynan berilgan 200px kenglikda qoladi, ichki bo'sh joy shu 200px ichidan "kesib olinadi".

content-box (sukut) 
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* haqiqiy kengligi:
   200 + 40 (padding) + 10 (border)
   = 250px */

Kutilmagan holda element kattaroq chiqadi — layout matematikasi buziladi.

border-box 
* {
  box-sizing: border-box;
}
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* haqiqiy kengligi baribir 200px,
   ichki bo'sh joy shu 200px ichidan
   "kesib olinadi" */

Element aynan berilgan 200px kenglikda qoladi — bashorat qilish oson.

Shuning uchun

Deyarli barcha zamonaviy loyihalarda dasturchilar eng boshida * { box-sizing: border-box; } deb yozib, barcha elementlarga shu qoidani qo'llab qo'yishadi — bu o'lchamlarni bashorat qilinadigan (predictable) qiladi.

Best practice

Yaxshi amaliyot — qisqacha

  • Har bir loyihaning boshida * { box-sizing: border-box; } yozing.
  • inline elementga o'lcham berishga urinmang — avval display qiymatini tekshiring.
  • Yonma-yon "tugma"ga o'xshash elementlar uchun inline-block qulay tanlov.
  • Elementni butunlay olib tashlash kerakmi yoki joyini saqlab, faqat yashirish kerakmi — buni oldindan aniqlab oling.
  • img — inline bo'lsa-da, "almashtiriladigan" (replaced) element sifatida width/height qabul qiladi — bu istisno.
Bugungi eng muhim xulosa

display — har qanday layout muammosining boshlanish nuqtasi. Element block, inline yoki inline-block ekanini bilish — keyingi darsdagi CSS Position mantig'ini tushunishning birinchi qadami.

Savol-javob

1. display: block va display: inline orasidagi ikkita asosiy farqni ayting.

1) Block — o'z qatorini egallaydi (yangi qatordan boshlanadi), inline — matn kabi yonma-yon oqadi. 2) Block'da width/height ishlaydi, inline'da ular e'tiborga olinmaydi.

2. inline-block nima uchun "aralash" hisoblanadi?

U inline elementlar kabi matn oqimida yonma-yon joylashadi, lekin block elementlar kabi width, height, padding qabul qiladi — ikkala turning xususiyatlarini birlashtiradi.

3. display: none bilan visibility: hidden orasidagi farq nima?

display: none — element sahifadan butunlay olib tashlanadi va joy egallamaydi. visibility: hidden — element ko'rinmas bo'ladi, lekin o'z joyini saqlab qoladi.

4. box-sizing: border-box nima uchun kerak?

Sukut holatda (content-box) padding va border width'ga qo'shilib hisoblanadi, natijada element kattaroq chiqadi. border-box bilan ular width ichiga sig'diriladi, shuning uchun element aynan berilgan o'lchamda qoladi — bu o'lchamlarni bashorat qilinadigan qiladi.

5. span elementiga width: 200px yozdingiz, lekin natija o'zgarmadi. Sabab nima?

span tabiatan inline element, inline elementlarga esa width/height ta'sir qilmaydi. Kerak bo'lsa display: inline-block yoki display: block qo'yish kerak.
